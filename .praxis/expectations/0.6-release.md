# E-006: 0.6 Release Quality Gates (v1.0.0)

## Zstd Compression

- **E-006a**: `zstd` crate is a dependency of `arca-core`
- **E-006b**: `import_store_path_compressed` accepts `Compression::Zstd` and `Compression::Xz`
- **E-006c**: zstd-compressed NARs have `.nar.zst` extension
- **E-006d**: xz-compressed NARs have `.nar.xz` extension
- **E-006e**: narinfo `Compression:` field reflects actual algorithm ("zstd" or "xz")
- **E-006f**: HTTP server sets `application/zstd` for `.nar.zst` files
- **E-006g**: HTTP server sets `application/x-xz` for `.nar.xz` files
- **E-006h**: Config file supports `compression = "zstd"` option
- **E-006i**: Default compression is zstd (not xz)
- **E-006j**: CLI `import --compression zstd|xz` flag works

## Garbage Collection

- **E-006k**: `gc` subcommand exists
- **E-006l**: `--max-age 30d` removes entries older than 30 days
- **E-006m**: `--max-size 10G` removes LRU entries to fit under size limit
- **E-006n**: Human-readable durations parsed ("30d", "7d", "1h")
- **E-006o**: Human-readable sizes parsed ("10G", "500M", "1T")
- **E-006p**: GC removes both narinfo and NAR data
- **E-006q**: GC records `GarbageCollect` events in audit log
- **E-006r**: GC prints summary with count and freed bytes
